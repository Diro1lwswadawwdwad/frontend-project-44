Правила игр
1. brain-even (Проверка на чётность)
Показывается случайное число. Нужно ответить:

yes — если число чётное

no — если число нечётное

2. brain-calc (Калькулятор)
Показывается математическое выражение (+, -, *). Нужно вычислить результат и ввести число.

3. brain-gcd (НОД)
Показывается два числа. Нужно найти наибольший общий делитель (НОД).

Что такое НОД?
НОД — это самое большое число, на которое делятся оба исходных числа без остатка.

Пример: НОД(25, 50) = 25

4. brain-progression (Арифметическая прогрессия)
Показывается ряд чисел, образующий арифметическую прогрессию, где одно число заменено на ... Нужно найти пропущенное число.

Что такое арифметическая прогрессия?
Последовательность чисел, в которой каждый следующий член получается прибавлением к предыдущему постоянного числа (шага прогрессии).

Пример: 5 7 9 11 13 .. 17 19 21 23 → пропущено число 15

5. brain-prime (Простое ли число?)
Показывается случайное число. Нужно ответить:

yes — если число простое

no — если число не простое

Что такое простое число?
Натуральное число, которое имеет ровно два различных натуральных делителя: 1 и само себя.

Примеры простых чисел: 2, 3, 5, 7, 11, 13, 17, 19, 23
